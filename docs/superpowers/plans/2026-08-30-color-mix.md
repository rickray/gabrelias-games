# Color Mix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new kids game called Color Mix to Gabrelia's Games where 4-year-old Gabrelia mixes primary colors to create target secondary colors with a massive screen celebration.

**Architecture:** Vanilla JS HTML5 canvas game adhering to Gabrelia's Games architecture (`GGShell.mount`, `GGScene`, `GGAudio`). Clean state machine (`start`, `round`, `celebrate`), giant tap targets (>150px), subtractive kid paint mixing rules, gentle wrong-mix recovery, and huge festive victory effects.

**Tech Stack:** Vanilla JavaScript (ES5/browser IIFE), Canvas 2D, Web Audio API / SpeechSynthesis (GGAudio), Service Worker cache (PWA), HTML/CSS.

## Global Constraints

- Static site, playable offline after first load.
- No new npm dependencies.
- Vanilla JS IIFE matching existing games (`games/which-box/`, `games/abc-zoo/`).
- Giant tap targets (>150px) supporting portrait and landscape.
- Speech prompts and names: red, yellow, blue, green, orange, purple.
- Clean subtractive paint mixing rules:
  - red + yellow = orange
  - yellow + blue = green
  - red + blue = purple
- Target colors: green, orange, purple.
- Source blobs: red, yellow, blue (shuffled).
- Tapping same blob twice does not mix (gentle bounce).
- Tapping target swatch repeats "Make [target]!".
- Wrong mix shows the blended color briefly, bowl wiggles, speech says e.g. "That's orange. Make green!", bowl empties, blobs remain for another try.
- Correct mix triggers HUGE celebration: color floods screen, giant splash, sunburst in mixed hue, confetti/sparkles in mixed color, result blob zooms to >50% of screen, cheer speech: "[Color]! You made [color]!" lasting ~3 seconds before next round.
- Hub tile added to `index.html` and `css/hub.css` without removing existing games.
- Service worker `sw.js` cache version bumped and files added.
- `tools/verify-games.mjs` updated and passing.
- `README.md` updated.
